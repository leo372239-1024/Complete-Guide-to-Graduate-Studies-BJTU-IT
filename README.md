# 北交软院读研全攻略手册

> 交流互鉴 · 互助共赢 — 面向北京交通大学所有计算机研究生的开源读研全攻略

本手册是一份面向北京交通大学（BJTU）所有计算机/软件工程研究生的开源读研全攻略手册，覆盖从入学到毕业就业的读研全阶段所有主题。手册受启发于「上海交大生存手册」，旨在打破信息差，将学长学姐走过的路、踩过的坑、用过的有效路径沉淀成一份可检索、可复用、可持续迭代的文档。

## 📖 手册内容

手册约 **1.3 万字**，包含以下核心板块：

| 板块 | 主要内容 |
|------|---------|
| **序章** | 前言、手册简介、适用人群、使用方法 |
| **学校板块** | 学校简介、校区介绍（海淀东/西校区、威海、雄安）、组织结构、联系方式、奖助学金 |
| **信息获取板块** | 校园墙、常用网站大全（26+ 网站）、常用公众号、常用 APP、通知渠道 |
| **入学板块** | 入学流程与时间节点、学习思维转变、新生体检、一卡通 |
| **就业板块（重点）** | 往届就业去向数据、商业公司就业指南（求职时间线/岗位选择/实习策略/面试准备）、考公考编就业指南、国企央企指南 |
| **生活板块** | 校历、校区地图、读研支出与收入、租房攻略、餐饮指南（19 个餐厅 + 校内外美食推荐 100+ 条目）、交通、运动设施、图书馆、医疗、校内服务、校外生活成本参考 |
| **学习与科研板块** | 研究方向、培养计划、选课指南、考试、毕业要求与学位论文流程、资源分享（PPT 模板/校徽/壁纸） |
| **校园文化** | 文体活动、社团、研究生会等学生组织 |
| **后记** | 编写初衷与寄语 |

## ✨ 特色亮点

- 📋 **全流程覆盖** — 从收到录取通知书到毕业离校，每个阶段都有对应指南
- 🍜 **硬核食堂攻略** — 早/午/晚餐分时段推荐，覆盖校内 19 个餐厅 + 校外周边美食，附价格参考
- 💼 **就业深度指南** — 包含往届就业去向数据分布，互联网/考公/考编/国企央企多条出路详解
- 🔗 **信息一站汇总** — 26+ 常用网站、8+ 公众号、6+ APP，入学即收藏
- 🏠 **实用生活贴士** — 租房避坑、交通出行、运动场馆、医疗公费等生活信息一应俱全
- 📖 **开源共创** — 永久开源，欢迎所有北交人提交 PR 共同完善
